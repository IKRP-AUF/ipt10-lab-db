# ipt10-lab-db

IPT10 Database Programming Laboratory: the same student-records CRUD app built twice.

- `ipt10_lab/` - procedural/OO **mysqli** version
- `ipt10_lab_pdo/` - **PDO** version
- `database.sql` - schema + sample data (`ip10_lab.students`, UUID primary key)
- `docs/` - TODO answers and report draft

## 1. Install XAMPP
Download from https://www.apachefriends.org/download.html (PHP 8.2+).
- **Windows:** run the installer (Apache, MySQL, PHP), open the XAMPP Control Panel, Start Apache and MySQL.
- **macOS:** `sudo /Applications/XAMPP/xamppfiles/xampp start`
- **Linux:** `sudo /opt/lampp/lampp start`

## 2. Enable PHP extensions
Edit XAMPP's `php.ini` and make sure these lines are **not** commented out (no leading `;`):
```
extension=mysqli
extension=pdo_mysql
```
Restart Apache. Check `http://localhost/phpinfo.php` shows both "mysqli" and "PDO / pdo_mysql" as enabled.

## 3. Create the database
Open `http://localhost/phpmyadmin`, go to the **SQL** tab, paste the contents of `database.sql`, click **Go**.
(Or: `mysql -u root < database.sql`.)

## 4. Deploy
Copy `ipt10_lab/` and `ipt10_lab_pdo/` into `XAMPP/htdocs/`.

## 5. Run
- mysqli: http://localhost/ipt10_lab/index.php
- PDO: http://localhost/ipt10_lab_pdo/index.php

Default credentials in code: host `127.0.0.1`, user `root`, empty password. Change them in
`db_connect.php` / `config.php` if yours differ. Pages use Bootstrap 5 from a CDN (internet needed for styling).

## Notes
- `id` is a UUID string generated by `UUID()` in SQL; there is no insert id, so writes are confirmed with `affected_rows` / `rowCount()`.
- Leaving *Student Number* blank auto-generates one (the column is NOT NULL + UNIQUE in the schema).

## Troubleshooting
- **`#1273 - Unknown collation: 'utf8mb4_0900_ai_ci'`** when importing the schema: XAMPP ships MariaDB, which does not have this MySQL 8 collation. `database.sql` already uses `utf8mb4_general_ci` instead.
